| Skip | `SkipSuggested`; no response/provenance/context, no rejection feedback. |
| Source correction | Existing Experience `Update`; new user revision; same transaction invalidates ordinary dependent content, making it visibly ineligible. No dependency substitution or automatic regeneration. |
| Source deletion | Existing Experience `Delete`; same transaction purges source and dependent text according to existing parent-delete policy; only approved content-free metadata remains. No physical secure-erasure guarantee. |

## Reuse and persistence boundary

The new `schema_v5_android_reflection.rs` admits a narrow same-source graph and
routes to the canonical Evidence/Reflection transactions. Explicit direct-origin
entry points use existing exact direct verifiers; default migration-origin
entry points keep their verification semantics. Apply-command bodies, immutable
events/revisions, projection transactions, rollback, manifests and verified
reread stay canonical. There is no alternate artifact schema, DDL change,
`INSERT OR REPLACE`, migration receipt fabrication or renderer persistence.

Fixed `com.lifeos.review.m2c` owns `android-m2c-disposable-v5.db` and honest
`android-m2c-direct-fresh-v5.receipt.json`; readiness reuses M2-A's exact
publication and durable pending-file retirement algorithm. The temporary facade
uses app-private paths only and serialized operations. Unknown, cross-source,
historical or unsupported dependency/provenance graphs are refused without
modifying them. Legitimate same-source Evidence/Reflection graphs do **not** use
M2-B's blanket artifact refusal.

Frontend domain types, context packets, sufficiency/gate checks, shared versions,
response authorship helper and the extracted unchanged pure placeholder question
function are reused. The local quote presenter says “Your own words” / “你寫下的原文” /
“あなたが書いた原文”; a subjective statement or quotation remains a self-report,
not proof that the event occurred. It does not inherit the older placeholder's
misleading “directly observable” presentation. Question localization translates
the existing neutral question, not a new behavior policy. No remote provider,
historical, Pattern, Growth or recovery path is imported into the M2-C bundle.

Head-qualified snapshots prevent compatibility statuses alone from granting
eligibility. Source editing invalidates dependent records; the UI labels them
not reusable and requires a new explicit user action. Only pending Evidence
correction/confirm/reject and suggested response save/skip controls are exposed;
no confirmed-artifact correction/deletion or response correction UI.
