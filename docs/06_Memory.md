# 06 Memory

> Life OS does not collect memories.  
> Life OS collects evidence.

Life OS 不只是收集記憶。

Life OS 收集的是能幫助使用者理解自己的證據。

Memory 在 Life OS 中不是資料倉庫，不是懷舊收藏，也不是讓 AI 擁有更多上下文的手段。Memory 是一套 evidence system：它讓人的經驗可以被保存、比對、修正，並逐漸形成對 Identity、Awareness、Growth 有意義的理解。

## What Memory Is Not

Life OS 的 Memory 不是：

- 每一天流水帳的完整保存。
- 對使用者所有生活細節的永久紀錄。
- 替 AI 囤積更多個人資料。
- 把過去變成無法修正的判決。
- AI 控制使用者的工具。

記住更多，不等於理解更深。

如果 Memory 只是累積資料，它會變成負擔。如果 Memory 沒有目的，它會變成噪音。如果 Memory 不能服務使用者的自我理解，它就不應被保存。

## Memory As Evidence

Memory 的核心目的，不是保存過去，而是形成 evidence。

一段記錄本身不一定有意義。

但當不同時間的事件、情緒、語句、選擇、關係與矛盾開始互相映照，它們就可能形成 evidence。

Evidence 讓 Life OS 不必依賴印象。

Evidence 讓 Identity 不必依賴宣告。

Evidence 讓 Awareness 不只是感覺。

Evidence 讓 Growth 不只是願望。

Life OS 的 Memory 必須能回答：

> 這段記憶如何幫助使用者更理解自己？

## From Experience To Evidence

Life OS 將 Memory 理解為一條從生活到成長的轉化鏈：

Experience  
→ Record  
→ Evidence  
→ Pattern  
→ Identity  
→ Reflection  
→ Growth

Experience 是發生過的事。

Record 是被保存下來的痕跡。

Evidence 是對理解使用者有意義的紀錄。

Pattern 是多個 evidence 在時間中形成的重複關係。

Identity 是 patterns 長期顯現出的方向與結構。

Reflection 是使用者回看這些 evidence 時產生的理解。

Growth 是理解之後，使用者更有主體性地修正、選擇與行動。

Memory 的價值，不在於停留在 Record。

Memory 的價值，在於讓 experience 有機會成為 evidence。

## What Should Be Remembered

Life OS 應優先記住能幫助使用者理解自己的內容：

- Significant events
- Emotional responses
- Repeated patterns
- Decisions and tradeoffs
- Values in action
- Relationship patterns
- Self-descriptions
- Contradictions
- Changes over time

不是所有內容都值得被記住。

Memory 應該服務自我理解，而不是服務資料累積。

一個重要事件值得被記住，不只是因為它發生了，而是因為它可能改變了使用者如何理解自己。

一個情緒反應值得被記住，不只是因為它強烈，而是因為它可能反覆出現，並揭露某個模式。

一個矛盾值得被記住，不是為了指責使用者，而是因為矛盾常常是理解 Identity 的入口。

## What Should Not Be Remembered

Life OS 不應貪婪地記住一切。

不應保存與自我理解無關、未經使用者同意、過度私密、過度敏感、沒有明確用途，或只會增加風險的資料。

Life OS 不應把使用者最脆弱的資料變成系統資產。

Memory 的邊界必須由使用者主體性、隱私與產品目的共同決定。

如果一段資料不能清楚說明它如何幫助使用者理解自己，就應該傾向不記住。

## Memory Requires Consent

Memory 必須建立在 consent 之上。

使用者應該能理解什麼被記住、為什麼被記住、如何被使用，以及如何修改或移除。

記憶不是系統單方面取得的權利。

記憶是使用者授權 Life OS 協助整理自我理解的信任關係。

因此，Memory 必須保護使用者的主體性，而不是削弱它。

## Memory Must Be Revisable

Memory 不是不可修改的真相。

人的理解會改變。使用者可能在未來重新理解某段關係、某個事件、某次選擇或某種情緒。

AI 可以提出過去的紀錄，但不能把過去變成永久標籤。

Memory 必須允許修正、補充、重新詮釋與刪除。

如果 Memory 不能被修正，它就可能成為另一種神諭。

## Memory And Identity

Memory 是 Identity 的 evidence。

Identity 不是由單一宣告建立，而是由長期 evidence 逐漸浮現。

這延續 `docs/05_Identity.md` 的核心句：

> Identity is revealed through patterns, not declarations.

Memory 讓 Life OS 看見 patterns。

沒有 Memory，Identity 會退回 self-description。沒有 evidence，AI 只能猜測使用者是誰。

Memory 不替使用者定義 Identity。

Memory 提供使用者理解 Identity 的材料。

## Memory And Reflection

Memory 的目的不是讓系統知道更多，而是讓使用者能更好地反思。

好的 Memory 應該幫助使用者問：

- 我是否曾經在不同情境中出現相似反應？
- 這個事件反映了什麼價值或恐懼？
- 我是否正在重複某個模式？
- 我是否已經和過去不同？

Memory 應該讓人更清楚，而不是更沉重。

它應該打開反思，而不是關閉解釋。

## Life OS Position

Life OS 的 Memory 不是為了讓 AI 更像一個知道一切的神諭。

Life OS 的 Memory 是為了讓使用者更有證據地理解自己。

它保存的不是過去本身，而是能夠支持反思、辨認模式、理解 Identity、促進 Growth 的 evidence。

Life OS 記住，不是為了控制使用者。

Life OS 記住，是為了把理解的主權交還給使用者。
